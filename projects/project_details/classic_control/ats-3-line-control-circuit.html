ATS 3-Line Control Circuit

ATSClassic ControlCADe SIMU

Project Overview

This CADe SIMU project demonstrates a three-line transfer-control concept. The three-phase utility line has first priority, the generator line is the second choice, and the third line is a simulated test source used only for demonstration—not a real supply.

Operating Principle

C line · UtilityGreen indicator · first priority
G line · GeneratorRed indicator · second priority
H line · Test sourceYellow indicator · test only
LOAD

KM1, KM2 or KM3 connects the selected line to the load indicator, with interlocking intended to prevent multiple contactors from closing together.

In the intended priority order, the controller selects the three-phase C line first. If it is unavailable, the generator line can be selected subject to R1/R2 logic and the 5-second delay. The H line is a simulated test option and should not override the utility or generator priority.

R1 — Utility line control

  • R1 monitors/controls the three-phase C line.
  • Timer T1 is set to 5 seconds before commanding KM1.
  • KM1 is interlocked with KM2 and KM3.
  • The C line has priority over the other lines.

R2 — Generator line control

  • R2 controls the generator G line.
  • Timer T2 is set to 5 seconds before commanding KM2.
  • KM2 is interlocked with KM1 and KM3.
  • R1 priority logic prevents the generator line from taking priority over the available C line.

KM3 — Test line

  • The H line has no dedicated control relay in this simulation; its contactor coil is controlled directly by the designed control logic.
  • KM3 is interlocked with the R1/R2 control logic and contactors KM1/KM2.
  • This line is for testing only, not a real third power source.

Line and load indicators

Green LED — C_MCB / utility line

Red LED — G_MCB / generator line

Yellow LED — H_MCB / test line

A separate LED connected to the contactor outputs represents the load.

Control Circuit

Main Components

Control-circuit protection

  • C_MCB — control MCB for the three-phase C line
  • G_MCB — control MCB for the generator line
  • H_MCB — control MCB for the test line

Power-circuit protection

  • MCCB — three-phase C-line power circuit, feeding KM1
  • MCB1 — generator power circuit, feeding KM2
  • MCB2 — test-line power circuit, feeding KM3

Control and switching devices

  • R1, R2 — control relays
  • T1, T2 — 5-second timers
  • KM1, KM2, KM3 — contactors for C, G and H lines respectively

Technical Notes

Design Areas to Verify

  • Source monitoring and transfer conditions
  • Contactor or switching-device ratings
  • Electrical and, where required, mechanical interlocking
  • Overcurrent protection and source isolation
  • Control-circuit protection and transfer timing
  • Cable sizing, short-circuit withstand, and protection coordination
Engineering Note

This is an educational CADe SIMU simulation. The H line and its MCB are test-only elements. The described 5-second timers and priority logic reflect the simulation as explained, not a certified ATS design. A real transfer system needs verified electrical interlocking, appropriate switching/protection ratings, source compatibility checks, and review against applicable standards before implementation.
