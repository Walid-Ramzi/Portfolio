CADe SIMU 3D Motor Control

CADe SIMU3D SimulationMotor ControlPersonal Project

Project Overview

A 3D presentation of an industrial motor-control circuit, developed from my electrical schematic to help visualize the control devices, contactors, timer relay, protection, and motor connections.

This project presents a 3D version of my motor-control schematic using CADe SIMU. The goal is to connect the logic of an electrical drawing with a clearer visual representation of the devices used in an industrial control circuit.

Operating Principle

The circuit shown includes a three-phase supply, motor protection, magnetic contactors, Start and Stop push buttons, an emergency-stop circuit, a timer relay, and a three-phase motor.

The step-by-step operating sequence for this circuit will be added.

Control Circuit

Main Components

  • Three-phase power supply
  • Circuit breakers and motor protection
  • KM1, KM2, KM3 — Magnetic contactors
  • Start and Stop push buttons
  • Emergency-stop circuit
  • Timer relay
  • Three-phase asynchronous motor
