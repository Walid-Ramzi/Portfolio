Project Overview

This project focuses on maintaining the liquid level in an industrial storage tank at a defined setpoint. A level sensor continuously measures the tank's fill state, and a PLC implements PID control logic to regulate a pump, ensuring stable and accurate level management.

Main Objectives

Design a control system that keeps the tank level within a narrow operating band despite varying inflow and outflow conditions, preventing overflow or underflow while minimizing pump cycling.

Solution

A ultrasonic level transmitter provides continuous measurement data to a Siemens PLC. A PID control loop processes the level signal and adjusts the pump output to maintain the setpoint. Proportional, integral, and derivative gains were tuned to achieve stable response without excessive oscillation.

Technologies Used

Instrumentation Level Measurement PID Control PLC Process Control Ultrasonic Sensor PID Tuning

System Components

  • Ultrasonic level transmitter
  • Siemens S7 PLC with analog input module
  • Pump with variable speed drive
  • Control valve for outflow regulation
  • Analog signal conditioning hardware
  • HMI for setpoint adjustment and monitoring

Development Process

The project began with process characterization — identifying the tank's dynamics, response times, and disturbance sources. The PID parameters were tuned systematically: starting with proportional-only control, then adding integral action to eliminate steady-state error, and finally adjusting derivative to improve settling time. Simulation in Factory I/O validated the control strategy before physical commissioning.

What I Learned

  • Achieved stable level control within ±2% of setpoint under variable conditions
  • Reduced pump wear through optimized cycling strategies
  • Developed practical PID tuning methodology for level control loops
  • Strengthened understanding of analog signal processing in PLC environments
