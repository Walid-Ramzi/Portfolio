Project Overview

This project implements a PLC-based automation system for a bottling production line. The system coordinates sensor input, actuator output, and timing sequences to move containers through filling, capping, and labeling stages automatically.

Main Objectives

Design and program a control system that increases production reliability and reduces manual intervention on the bottling line. The system must handle container detection, liquid filling, cap application, and product count tracking.

Solution

A Siemens PLC was programmed in TIA Portal to manage the full production sequence. Sensors detect container presence at each station, timers control fill duration, and actuators operate caps and labeling mechanisms. Factory I/O was used for simulation and visualization before deployment.

Technologies Used

Siemens TIA Portal PLC Programming Factory I/O Sensors Actuators Timers Industrial Automation

System Components

  • Siemens S7 PLC (CPU + I/O modules)
  • Proximity sensors — container detection
  • Photoelectric sensors — fill level monitoring
  • Pneumatic cylinders — cap application
  • Conveyor motor drives
  • HMI panel for operator interface
  • Timer and counter function blocks

Development Process

The project followed a structured methodology: requirements analysis, system design in Factory I/O, PLC program development in TIA Portal, simulation testing, and final commissioning. Each production stage was mapped to a dedicated function block in the PLC program, enabling modular troubleshooting and future expansion.

What I Learned

  • Reduced manual operator intervention at the filling station
  • Implemented reliable container-count tracking across all stages
  • Gained practical experience with Siemens TIA Portal and Factory I/O simulation
  • Developed modular PLC programming practices using function blocks
