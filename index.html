The controller recalculates its output every cycle from five numbers. Here's the same math the diagram above is running, broken into steps, with the live values plugged in.

1 Error — how far off the setpoint is
Error = Setpoint − Measured value (PV)
Error = 40.0 °C − 37.6 °C = +2.4 °C
2 Proportional (P) — reacts to the error right now
P = Kp × Error
P = 2.0 × +2.4 °C = +4.8%
3 Integral (I) — clears any long-term offset
I = Kp × (Σ Error · dt) ÷ Ti
I = 2.0 × (84.0 °C·s) ÷ 30 s = +5.6%
4 Derivative (D) — resists sudden changes
D = Kp × Td × (Error − Previous error) ÷ dt
D = 2.0 × 5 s × (+2.4 °C − +2.2 °C) ÷ 5 s = +0.4%
= Output — what actually drives the heater
Output = Bias + P + I + D (clamped to 0–100%)
Output = 54.0% + +4.8% + +5.6% + +0.4% = 64.8%

Profile

About Me

I'm an Instrumentation & Automation Engineer based in Remchi, Tlemcen, Algeria. I hold a Bachelor's degree in Electronics (2023) and a Master's (M2) in Instrumentation (2026), both from Université Abou Bekr Belkaid, Tlemcen.

My final-year project, CoopMaster, is a smart automated poultry-coop system built around a Raspberry Pi, combining sensors, an automated door, camera monitoring and a companion Flutter app.

I'm preparing to enter the industrial automation and instrumentation field, with particular interest in oil & gas, power plants and process industries, while continuing to build practical skills in Siemens TIA Portal, Factory I/O and industrial control practices.

In parallel, I build Flutter web applications with Supabase backends — including an e-commerce storefront with an admin dashboard and a multi-app delivery platform — which feeds back into how I design the software side of automation and monitoring systems.
